# Zbierka úloh MO (Z5–Z9)

Úlohy Matematickej olympiády pre základné školy (kategórie Z5–Z9, od 2008/2009) na jednom mieste:
filtrovanie podľa kategórie, kola, roka, oblasti, metódy riešenia a náročnosti, riešenia pri každej úlohe
a tvorba tlačiteľných pracovných listov.

Zadania a riešenia sú výrezy z oficiálnych materiálov Slovenskej komisie MO (https://skmo.sk).
Zaradenie úloh (oblasť, metóda, náročnosť) je pomôcka, nie oficiálne hodnotenie.
Vlastné úlohy a pracovné listy sa ukladajú len v prehliadači používateľa.

Autorka: Veronika Csiba, Gymnázium Grösslingová, Bratislava. Vytvorené spolu s Claude (Anthropic).
